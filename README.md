# AdventureWorks2022 SQL Analysis

## Overview

This project focuses on business data analysis using the AdventureWorks2022 database in Microsoft SQL Server. The objective is to explore sales performance, customer behavior, and product information through SQL queries to support business decision-making.

---

## Objectives

- Analyze sales and customer data.
- Extract meaningful business insights.
- Practice SQL for real-world business scenarios.

---

## Technologies

- SQL Server
- T-SQL
- AdventureWorks2022 Database

---

## Skills Applied

- JOIN
- GROUP BY
- HAVING
- Common Table Expressions (CTE)
- Window Functions
- Subqueries
- Aggregate Functions

---

## Project Tasks

- Analyze sales performance.
- Explore customer purchasing behavior.
- Analyze product and category information.
- Generate business reports using SQL queries.

---

## Learning Outcomes

- Improved SQL querying skills.
- Strengthened relational database knowledge.
- Gained experience in business data analysis using SQL Server.
